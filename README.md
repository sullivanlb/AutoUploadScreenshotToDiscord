# AutoUploadScreenshotToDiscord

This application will run in the background and allow you to have a shortcut that will automatically take a screenshot and send it to the discord channel of your choice!

![AutoUploadScreenshotToDiscordIcon](https://github.com/user-attachments/assets/420b149d-a0ac-4146-8915-4f35ee3b6501)

## How does it works ?

1. Run the .exe
2. Setup the Webhook's URL, this will tell the program where to send the message. (If you don't know what it is you can know more about it here : https://support.discord.com/hc/en-us/articles/228383668-Intro-to-Webhooks)
3. Setup the shortcut
4. Setup the directory where the temporary image will be stored
5. Press "Start" and your good to go!
